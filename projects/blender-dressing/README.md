# Blender Dressing

Status: planned.

## Mission

Bring an approved simulated garment and an avatar/body into Blender using repeatable semantic asset mapping.

## Initial v0.1 scope

- import one known avatar
- import one garment exported from CLO
- reconcile garment objects using garment metadata
- place/associate garment with avatar
- configure a minimal cloth/mesh workflow
- save a `.blend`
- render a verification image

## Non-goals for v0.1

- arbitrary-avatar automatic fitting
- changing source pattern geometry
- rediscovering seam topology
- full production rigging pipeline

## Future

- multiple avatars
- automated fitting
- animation
- render turntables
- Unity / Unreal export
